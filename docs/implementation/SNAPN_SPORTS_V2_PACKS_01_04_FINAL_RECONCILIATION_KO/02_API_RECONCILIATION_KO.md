## 2. Decision rules

`EXISTING_OPENAPI` → call canonical physical op.  
`EXISTING_LOGICAL_CONTRACT` → consume owner Pack; do not duplicate.  
`OPENAPI_PROMOTION` → add to physical OpenAPI without redefining business intent.  
`PATH_RECONCILIATION` → physical path/aggregate wins; aliases remain migration-only.  
`INTERNAL_USE_CASE_ONLY` → application service/projection, no public REST.  
`ADMIN_PROJECTION_ONLY` → permission-scoped read model, not a domain endpoint explosion.  
`REAL_API_EXTENSION` → only when no existing physical/logical/internal model can preserve required truth.  
`DEFERRED` → infrastructure/write-owner/production gate unresolved.  
`REJECTED` → endpoint shape rejected while required functionality is preserved elsewhere.
